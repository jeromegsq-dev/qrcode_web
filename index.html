Pour la classe

Quelques façons simples d'utiliser un code QR avec vos élèves.

Fiches et exercices

Imprimez un code sur la fiche. Les élèves le scannent pour ouvrir la correction, une vidéo ou un document.

Devoirs à la maison

Mettez le lien du formulaire ou du document partagé sur le tableau. Plus besoin de le dicter.

Affiches et sorties

Affichez un code dans le corridor ou à la bibliothèque, par exemple pour un projet ou une activité de sortie.

Comment ça marche

Trois étapes, moins d'une minute.

  1. 1

    Collez votre lien

    Copiez l'adresse de la page, du document ou du formulaire que vous voulez partager.

  2. 2

    Vérifiez avec votre téléphone

    Ouvrez l'appareil photo de votre téléphone et pointez-le vers le code à l'écran.

  3. 3

    Téléchargez et imprimez

    Le PNG convient à Word et aux courriels. Le SVG reste net pour une grande affiche.

Avant d'imprimer

Quelques conseils pour que le code se lise bien du premier coup.

Assez grand

Visez au moins 2 cm de côté. Pour une affiche, la largeur doit être d'environ un dixième de la distance de lecture.

Noir sur blanc

Un code foncé sur fond clair se lit mieux. Évitez les couleurs pâles et les fonds sombres.

Testez d'abord

Imprimez une copie, placez-la à la distance réelle des élèves et scannez-la avec deux téléphones.

Questions fréquentes

Une autre question ? Écrivez-nous à contact@exemple.ca.

Est-ce vraiment gratuit ?

Oui. Vous pouvez créer et télécharger autant de codes que vous voulez, sans compte et sans filigrane.

Mes liens sont-ils envoyés quelque part ?

Non. Le code est dessiné directement dans votre navigateur. Le lien que vous collez n'est ni envoyé ni enregistré.

Un code imprimé peut-il expirer ?

Le code contient votre lien tel quel. Il fonctionne tant que la page ou le document existe. Si vous changez de lien, il faudra imprimer un nouveau code.
